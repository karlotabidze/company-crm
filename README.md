# Company CRM

Bitrix24-ის მსგავსი CRM სამუშაო სივრცის საწყისი ვერსია — React + Vite.

## ფუნქციები
- მიმოხილვის გვერდი KPI ბარათებითა და გაყიდვების მილსადენით
- გარიგებების სია, ძიება და ეტაპების შეცვლა
- ახალი გარიგების დამატება
- დავალებების სია და შესრულების მონიშვნა
- კონტაქტების, კომპანიებისა და ანალიტიკის განყოფილებების საწყისი UI
- ქართული ინტერფეისი და ადაპტიური დიზაინი
- გარიგებების დემო-მონაცემები ინახება ბრაუზერის localStorage-ში

## გაშვება

Node.js 20.19+ ან 22.12+:

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## მნიშვნელოვანი
ეს რეპოზიტორია ამ ეტაპზე შეიცავს ფრონტენდის სამუშაო დემო-ვერსიას. მონაცემები ინახება მხოლოდ მიმდინარე ბრაუზერში; მომხმარებლების ავტორიზაცია, როლები, საერთო მონაცემთა ბაზა, API და რეალური მრავალმომხმარებლიანი სინქრონიზაცია ჯერ არ არის დაკავშირებული. რეალურ CRM-ად გამოსაყენებლად საჭიროა backend/API, მონაცემთა ბაზა და ავტორიზაციის კონფიგურაცია.
